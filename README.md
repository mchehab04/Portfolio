# Mohamad Chehab — Personal Portfolio

A sleek, responsive personal portfolio website showcasing projects in **Full-Stack Development**, **Machine Learning & Data Science**, and **Robotics & Industrial Automation**.

Live GitHub Repository: [https://github.com/mchehab04/Portfolio](https://github.com/mchehab04/Portfolio)

---

## 🚀 Overview

- **Design Aesthetic:** Modern light-mode interface built with bespoke glassmorphism, fluid typography, and curated gradients.
- **Interactive Filtering:** Filter featured projects by category (*Full-Stack & Systems*, *AI & Data Science*, *Robotics & Automation*).
- **Lightweight & Fast:** Pure vanilla web technologies with zero build steps, sub-second load times, and responsive layout across all device sizes.
- **SEO & Accessibility:** Structured semantic HTML5, ARIA labels, and Open Graph metadata.

---

## 🛠️ Tech Stack

- **Markup:** Semantic HTML5
- **Styling:** Vanilla CSS3 (CSS Variables, Flexbox & Grid, Glassmorphic effects, Micro-animations)
- **Scripting:** Vanilla JavaScript (ES6+, DOM filtering, IntersectionObserver scroll animations)
- **Fonts:** Google Fonts ([Inter](https://fonts.google.com/specimen/Inter) & [Outfit](https://fonts.google.com/specimen/Outfit))
